**Требования к безопасности**
- шифрование, при передаче данных по сети
- мониторинг и логирование системы 
- резервное копирование данных с четкой классификацией данных
- процесс анонимизации данных (Имеется система распознования лиц. Это биоданные, нужно быть придельно осторожными)
- разработать систему и процессы контроля сохранности данных 

**Аутентификации и авторизации**

- аутентификация - двухфакторная автоизация (логин/пароль + смс/звонок). Использем OAuth 2.0. 

- авторизация - система должна определить пользователя и ограничить согласно ролевой модели

**Взаимодействие между системами**

- "Умный дом" выделин в отдельный сервис. Сервис взаимодействует с внешними партнерскими сервисами по REST/WebSocket
- Обмен данными шифруется
- Производится мониторинг и логирование с обеих сторон системы
- Проводится аудит безопасности партнерских сервисов (раз в n-период)
